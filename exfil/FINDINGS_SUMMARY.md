## ATTACK CHAINS

### Chain 1: Mass Account Takeover
1. Bypass OTP: `VeriftyOtpstoUser(UserName, SchoolId, "")`
2. Reset Password: `ResetStdPassword(UserName, SchoolId, "NewPassword")`
3. Login as student
4. Escalate privileges

### Chain 2: Google API Abuse
1. Use API key for Cloud Vision (label detection, OCR)
2. Use API key for Cloud Translation
3. Cost run-up potential: Tens of thousands per day

### Chain 3: S3 Data Access
1. Enumerate S3 bucket paths via DisplayFile
2. Access sensitive documents (assignments, student data, configs)

## REMEDIATION
1. Fix OTP validation - reject empty/blank OTP values
2. Require valid OTP session token for ResetStdPassword
3. Restrict Google API key with HTTP referrer/IP restrictions
4. Rotate AWS access key and implement bucket policies
5. Enable customErrors=RemoteOnly
6. Implement proper authentication for GetERPUserDetails
7. Restrict file upload extension validation to whitelist only
8. Disable trace.axd in production
